# City Living MX

## 📖 Descripción del Proyecto
City Living MX es un sistema de software de alta calidad diseñado para la administración de usuarios y renta de departamentos en las ciudades más populares de México. La plataforma facilita una dinámica colaborativa donde los usuarios pueden poner en renta sus propias propiedades, así como buscar y rentar los espacios publicados por otros miembros de la comunidad.

## 🚀 Características Principales
El sistema cuenta con los siguientes módulos funcionales:
- **Seguridad:** Registro y autenticación de usuarios con perfiles seguros.
- **Gestión de Propiedades:** Publicación detallada de inmuebles por parte de los dueños.
- **Búsqueda y Exploración:** Herramientas para facilitar la búsqueda y renta de departamentos para los usuarios interesados.
- **Administración Legal y Financiera:** Gestión interna de contratos y simulación de pagos básicos.
- **Panel de Administración:** Control y gestión centralizada de la información tanto de propiedades como de usuarios.

## 🛠️ Stack Tecnológico
El proyecto está diseñado como una aplicación de escritorio, pensado para ser ejecutado y probado de manera óptima en entornos Linux (como Fedora o Ubuntu) y Windows (10/11).

* **Lenguaje de Programación:** Java
* **Entorno de Desarrollo (IDE):** IntelliJ IDEA
* **Base de Datos:** PostgreSQL
* **Control de Versiones:** Git / Repositorio en GitHub

## ⚙️ Instalación y Configuración

### Requisitos Previos
Para poder ejecutar y modificar este proyecto, asegúrate de cumplir con los siguientes requisitos en tu sistema:
- **Sistema Operativo:** Linux (recomendado y testeado en distribuciones como Fedora o Ubuntu) o Windows (10/11).
- **Java Development Kit (JDK):** Versión instalada y configurada en las variables de entorno.
- **Base de Datos:** Motor de PostgreSQL instalado y corriendo localmente (o en servidor).
- **IDE:** IntelliJ IDEA (Community o Ultimate).
- **Control de versiones:** Cliente de Git instalado.
